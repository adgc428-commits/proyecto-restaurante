# La Buena Mesa — Proyecto de restaurante

Proyecto escolar de una página web para un restaurante.

## Archivos
- `index.html`: estructura y contenido de la página.
- `styles.css`: diseño, colores y adaptación a celulares.
- `script.js`: interacción del botón de contacto.

## Cómo abrirlo
Abre el archivo `index.html` en un navegador web.

## Publicarlo en GitHub
Crea un repositorio nuevo en GitHub y sube estos cuatro archivos.
